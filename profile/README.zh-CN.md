# Dream Bridge Lab

[English](https://github.com/dreambridgelab) · **简体中文**

我们为创业者和小团队开发范围明确的网页应用、AI 原型与工作流自动化。带来一个具体的工作流程、使用它的人，以及首版需要完成的一件事，就可以开始讨论。

## 可以承接的三类项目

| 项目类型 | 适合的起点 |
| --- | --- |
| AI 网页应用与 MVP 原型 | 围绕一个可操作的流程，明确输入、AI 输出、界面与验收条件。 |
| 工作流自动化与 API 集成 | 校验输入数据，连接约定的工具，让数据交接过程便于检查。 |
| 内部工具 | 为超出表格承载范围的工作，开发专用表单、看板或数据工具。 |

## 案例与演示

### AIPrice Global：独立开发的自有产品

用于浏览模型价格、按实际工作量估算 API 费用。实现包括 Python 目录导入器、可交互的 JavaScript 前端与 Cloudflare 部署。

[阅读完整案例](https://github.com/dreambridgelab/.github/blob/main/case-studies/aiprice/README.zh-CN.md) · [体验产品](https://yourdreamlab.net/apps/aiprice/)

### n8n 线索接收：合成数据演示

一个七节点工作流：检查四条虚构线索、识别重复数据，并准备模拟表格行与通知。已在本机执行验证；它展示工作流程，不代表客户部署。

[阅读演示案例](https://github.com/dreambridgelab/.github/blob/main/case-studies/n8n-lead-intake/README.zh-CN.md) · [查看工作流 JSON](https://github.com/dreambridgelab/.github/blob/main/demos/lead-intake-n8n.json)
