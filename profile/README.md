We build focused web apps, AI prototypes, and workflow automations for founders and small teams. Bring a concrete workflow, the people who use it, and one useful outcome for the first version.

| Project type | A practical starting point |
| --- | --- |

| Workflow automation & API integration | Validate incoming data, connect agreed tools, and make handoffs easier to inspect. |
| Internal tools | A focused form, dashboard, or data tool for work that has outgrown spreadsheets. |

A model pricing explorer and workload cost calculator. Built with a Python catalog importer, an interactive JavaScript front end, and Cloudflare hosting.

### n8n lead intake — synthetic demo

A seven-node workflow that checks four fictional leads, finds a duplicate, and prepares mock rows and notices. Tested locally; it is a demonstration of the workflow rather than a customer deployment.

[Read the demo case](https://github.com/dreambridgelab/.github/blob/main/case-studies/n8n-lead-intake/README.md) · [Inspect the workflow JSON](https://github.com/dreambridgelab/.github/blob/main/demos/lead-intake-n8n.json)
